# 🔐 Generador de Contraseñas con JavaScript

Mini proyecto desarrollado en JavaScript como parte del módulo de **Dominando el DOM de DEV.F**.

## 📌 Descripción

Página web interactiva que permite generar contraseñas y personalizadas, seleccionando su longitud y los tipos de caracteres que se desean incluir.

## ⚙️ Funcionalidades

- Generar contraseñas aleatorias de 9 a 32 caracteres.
- Seleccionar letras mayúsculas, minúsculas, números y símbolos.
- Ajustar la longitud mediante un control deslizante.
- Copiar la contraseña generada al portapapeles.
- Mostrar mensajes de confirmación al usuario.

## 💻 Tecnologías

- HTML5
- CSS3
- JavaScript

## 🚀 Ejecución

1. Abrir el proyecto en Visual Studio Code.
2. Ejecutar `index.html` con Live Server.
3. Seleccionar la longitud y los tipos de caracteres.
4. Presionar **Generar contraseña**.
5. Copiar la contraseña utilizando el botón correspondiente.

## 🎯 Objetivo

Practicar la manipulación del DOM, el manejo de eventos y la lógica de programación mediante el desarrollo de una herramienta interactiva para generar contraseñas.
